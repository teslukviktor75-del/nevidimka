# Nevidimka

Невеликий інтерактивний UI-прототип сервісу знайомств для повнолітніх (18+), створений на Next.js.

## Запуск локально

```bash
npm install
npm run dev
```

Відкрийте http://localhost:9002.

## Важливо

Це демо інтерфейсу: профілі й повідомлення демонстраційні, серверного збереження, автентифікації, завантаження фото/відео, відеодзвінків, платежів або донатів ще немає. Не вводьте реальні персональні чи платіжні дані.

Знайомства, приватні повідомлення, медіа, дзвінки та подарунки/донати призначені виключно для повнолітніх. Nevidimka не надає неповнолітнім кімнат знайомств, приватних чатів, відеодзвінків або обміну медіа. Перед публічним запуском потрібні надійна перевірка віку, модерація, скарги/блокування, політика приватності та безпечна платіжна інтеграція.
